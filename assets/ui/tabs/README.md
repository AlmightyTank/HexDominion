# Sidebar symbols

Six original, hand-authored SVG symbols created for Hex Frontlines at the user's request. No third-party icon library or external source was used.

20x20 transparent sources, displayed at 16 px alongside text labels:
- Army: squad, representing group management.
- Production: gear, representing manufacturing queues.
- Sites: map pin, representing inspected locations and facilities.
- Structures: building, representing construction.
- Infantry: helmet, representing foot soldiers.
- Vehicles: overhead tracked tank, matching the game's vehicle view.

The pale monochrome palette follows existing HUD text, leaving faction colors to game entities and state colors to feedback. Text labels remain visible so users do not have to memorize the symbols.
