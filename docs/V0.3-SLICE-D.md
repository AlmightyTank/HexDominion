# v0.3 Slice D: Continent bonuses

Each fully owned eligible continent grants its faction +10% income. Bonuses stack
additively across continents and apply to HQ, city and extractor base income.
Roads still add 10% to eligible city/extractor base income only: two continents
and a road yield 130% of that location's base, not 132%. Isolated locations remain
at zero; continent control does not bypass supply, power or construction rules.

## Eligibility and updates

The existing map's continent labels define regions. At match initialization a
single land flood fill from all starting units fixes the reachable components.
Ocean, land with `capturable: false`, and land unreachable from every starting
army are excluded. Thus remote islands and Antarctica cannot block a bonus.
Regions with no eligible land are displayed as excluded and award nothing.
Eligibility never shrinks when units die or ownership changes. No naval transport
exists yet; adding it will require revisiting this eligibility policy.

`TerritoryState.set_owner` updates centralized `ContinentControl` counts only
when ownership actually changes. Capture completion uses this API. Ownership
replacement during load recounts once. Runtime callers must use `set_owner`,
not mutate individual entries in `owners` directly. Initial scenario setup may
populate owners before configuring the manager. Contested land still belongs to
its current owner until capture completes, although supply can already be cut.

Counts and bonuses are derived, never serialized or paid as discrete rewards.
Legacy saves reconstruct them from ownership using the current map eligibility.
HQ capture remains the match victory condition; continents are economic only.

## Interface and verification

A bounded, scrollable sidebar overview shows each region's controller, both
factions' counts and remaining territories, excluded regions and active bonuses.
It refreshes only when the control revision changes. Existing HUD styling is
retained to distinguish this economic overview from map commands; no assets added.

Tests cover partial/exact ownership, loss/recapture, additive multiple regions,
both factions, unreachable and explicit exclusions, duplicate capture events,
road removal, supply interruption and real match save/load and HUD text.

Run `Godot --headless --path . --script res://tests/run_smoke_tests.gd`.
Interactive layout, keyboard, touch, contrast and the session's afterward UI audit
remain pending; automated HUD state checks are not visual acceptance.
