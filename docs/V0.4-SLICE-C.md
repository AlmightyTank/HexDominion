# v0.4 Slice C: long-range artillery

## Integration and tuning

Self-Propelled Artillery uses the existing factory, UnitState, weighted land pathfinder, cooldown combat, orders, selection and save validation. `UnitCatalog` defines its cost (200 CR), training (10 seconds before power slowdown), health (110), movement (0.95 seconds per ordinary hex), range (3), damage (45), cooldown (3 seconds), infantry multiplier (0.6), armor multiplier (0.5), and structure multiplier (3).

It is a support vehicle, not an assault tank: low health, slow movement and slow firing leave it vulnerable at close range. Stationary artillery automatically attacks enemy ground units or structures within hex range. Moving artillery does not fire. There is no minimum range or splash damage. No friendly fire is enabled.

An explicit Attack on an enemy structure keeps the bombardment focused even when defending units share its hex. Other automatic attacks retain the existing unit-first priority and single cooldown budget. Structures receive 135 damage per shell; unit damage still applies armor counters, terrain cover and bunker protection. Indirect fire does not require line of sight or a traversable corridor between firing and target hexes. An in-range attack across disconnected land works without driving onto the target. Out-of-range pursuit uses the existing land pathfinder.

Artillery cannot capture territory, either by occupying a hex or by firing into it. Infantry/other capture-capable vehicles must follow the bombardment. Move, Attack and Hold use existing controls; invalid/destroyed targets release pursuit. The current game has no Attack-Move order, so this slice does not advertise an unimplemented control. Hold retains existing automatic defensive fire.

## Presentation

The approved stack-first presentation remains: every zoom shows one dominant-role icon and deployed count per faction/hex, with exact type counts in the existing army panel. The existing artillery SVG supplies a distinct strategic icon. Selecting its composition row shows firing-range hexes. Expand reveals grouped/individual guns at medium/close zoom without changing simulation membership or losing tanks/APCs in the composition list.

The original procedural top-down artillery appearance uses a wider tracked chassis, a broad rear fighting compartment, faction stripe, an independently rotating long cannon extending well beyond the hull, muzzle brake and recoil. Shared selection and health indicators remain. Tanks retain their smaller hull and shorter barrel.

Actual combat volleys emit bounded transient shell effects, with an arcing flight followed by a small expanding impact. Damage resolves immediately on the existing simultaneous volley tick, not at visual impact time. These effects never apply secondary damage, retain target objects or survive loading. A destroyed target does not cancel its already-fired visual shell. At most 128 visual shells are retained; multiple shots in one large simulation tick coalesce to one visual per gun.

## Save compatibility

Artillery uses the shared stable unit ID and existing saved cooldown/turret/order state. Factory queue validation now uses the queued type's configured duration rather than the old eight-second global cap. Old saves need no migration. Visual shells and range overlays are derived/transient and are cleared/rebuilt on load.

## Verification

`tests/artillery_tests.gd` covers both factions' costs, timed low-power production, exact range/cooldown, defending units versus explicit structure orders, bunker destruction, terrain/armor/shelter multipliers, friendly rejection, target loss, close assault vulnerability, movement, non-capture, disconnected in-range attacks, factory control registration and exact save roundtrips with a nine-second production job.

`tests/artillery_visual_test.gd` renders far/medium/close markers, expanded medium/close mixed armies, selected range, rotation/recoil, shell flight and impact. It checks that real volleys create effects and feedback changes image pixels. CI runs both suites and uploads captures with the existing visual artifacts.

Local results: 73 artillery checks, 1,190 smoke checks, 134 vehicle checks and 724 artwork checks passed with zero failures. HUD regressions, headless startup and real OpenGL artillery captures also passed.

The existing RTS direction and stack-first interaction are retained; there is no unrelated interface redesign. Renderer captures and automated handlers are not physical touchscreen, full keyboard/contrast acceptance or competitive balance playtests. The session's afterward UI audit remains pending. Rival purchasing still uses its previous infantry/tank policy; it can operate artillery supplied by a scenario but does not buy it yet.
